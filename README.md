# session-map

Жива мапа сесії Claude Code: ціль (і як вона змінювалась), етапи, які вже пройдено, і побічні задачі, на які робота відгалужувалась.

```
◎ Візуальна мапа прогресу для кожної сесії Claude Code
├ ✓ Розібрали варіанти: задачі, CLAUDE.md, артефакт, мод
├ ✓ Написали мод session-map
├ ✓ ↳ Чи працює на телефоні? → дерево видно в чаті на телефоні
│ └ ✓ Додали дерево прямо в чаті (для телефону)
├ ▶ Винести мод у GitHub-репозиторій  ← зараз
└ ○ Увімкнути в усіх сесіях
```

## Як це працює

- Claude отримує інструмент `mcp__session-map__update` з діями `goal`, `plan`, `step`, `branch`, `return` та інструкцію в системному промпті: коли ставити ціль, фіксувати етап, відкривати й закривати побічну задачу. Для одного питання чи дрібної правки мапа не ведеться.
- Мапу видно:
  - у бічній панелі «Session map» (термінал, десктоп);
  - у чаті під останнім оновленням мапи (на телефоні теж), попередні оновлення згортаються в один рядок;
  - у статус-рядку: `◎ ціль · ↳ побічна задача`.
- Якщо 25 викликів інструментів пройшли без оновлення мапи, Claude отримує одне тихе нагадування.
- Мапа зберігається між запусками: відновлена сесія (`--resume`) показує її знову.

Команди: `/session-map` відкриває панель, `/session-map text` виводить мапу текстом, `/session-map reset` очищає її.

## Встановлення

### Локально: термінал, десктоп-апка, VS Code

У терміналі, у сесії Claude Code:

```
/plugin install session-map --marketplace avaver/claude-session-map
```

На запит `Add marketplace?` дай відповідь `y`, потім обери scope **user**. Мод працюватиме в кожній новій сесії на цьому комп'ютері, зокрема в локальних сесіях десктоп-апки.

### Хмарні сесії: claude.ai/code і мобільна апка

Хмарна сесія не ставить плагіни ні з user-налаштувань, ні з `.claude/settings.json` репозиторію. Мод підключається через налаштування хмарного оточення:

1. **Setup script**:
   ```bash
   git clone --depth 1 https://github.com/avaver/claude-session-map /root/claude-session-map
   ```
2. **Environment variables**:
   ```
   CLAUDE_CODE_PLUGIN_DIRS=/root/claude-session-map
   ```

Нові сесії в цьому оточенні стартуватимуть із мапою.

## Розробка

```bash
claude plugin validate .
claude plugin test .
```

Код: `hooks/map.ts` містить логіку дерева, `hooks/register.tsx` містить інструмент, панель, рядок у чаті та статус-рядок, а `types/index.d.ts` описує стан мода.
