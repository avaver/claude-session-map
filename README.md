# session-map

Жива мапа сесії Claude Code: теми сесії (задачі, баги, прохання), етапи, пройдені в кожній, і побічні задачі, на які робота відгалужувалась.

```

├ ✓ Створили репозиторій
├ ✓ ↳ Чи працює на телефоні? → дерево видно в чаті на телефоні
│ └ ✓ Перевірили на телефоні
├ ▶ Маркетплейс і встановлення  ← зараз
└ ○ Увімкнути в усіх сесіях

Раніше
✓ Написати мод session-map · 4 ✓
✓ Розібрати варіанти мапи · 2 ✓
```

## Як це працює

- Claude отримує інструмент `mcp__session-map__update` з діями `topic`, `goal`, `plan`, `step`, `branch`, `return` та інструкцію в системному промпті. Для одного питання чи дрібної правки мапа не ведеться.
  - `topic` починає нову тему, коли робота переходить на іншу задачу; етапи попередньої лишаються під нею. Назва попередньої теми повертає до неї.
  - `goal` переформульовує поточну тему, коли та сама задача уточнюється.
  - Етапи (`step`, `plan`) і побічні задачі (`branch`, `return`) записуються в поточну тему.
- Мапу видно:
  - у панелі «Session map»: поточна тема повністю, попередні по рядку з підсумком (`✓` усе зроблено, `◐` лишились пункти, `▶` етап покинуто на півдорозі);
  - у чаті: кожне оновлення займає один рядок про те, що змінилось. Мапу з усіма темами повністю показує `/session-map text`, на телефоні, де панелі немає, теж;
  - у статус-рядку: `◎ ціль · ↳ побічна задача`.
- Якщо 25 викликів інструментів пройшли без оновлення мапи, Claude отримує одне тихе нагадування.
- Мапа зберігається між запусками: відновлена сесія (`--resume`) показує її знову. Мапа з версії до тем ділиться на теми за часом: кожен етап іде до формулювання цілі, чинного, коли його записали.

Команди: `/session-map` відкриває панель, `/session-map text` виводить мапу текстом, `/session-map reset` очищає її.

### Де з'являється панель

- У терміналі панель стоїть збоку від чату лише в повноекранному режимі: `/tui fullscreen`, від 110 колонок. У звичайному режимі `/session-map` відкриває її над полем вводу.
- Сама, без команди, панель відкривається, коли термінал має від 144 колонок, або від 110, якщо ти вже відкривав її командою. Вужче вона чекає, доки відкриєш її або розшириш вікно.
- Старіші версії десктоп-апки панелей не показують. Якщо панель не з'явилась, `/session-map` скаже чому.

## Встановлення

### Локально: термінал, десктоп-апка, VS Code

У терміналі, у сесії Claude Code:

```
/plugin install session-map --marketplace avaver/claude-session-map
```

На запит `Add marketplace?` дай відповідь `y`, потім обери scope **user**. Мод працюватиме в кожній новій сесії на цьому комп'ютері, зокрема в локальних сесіях десктоп-апки.

### Хмарні сесії: claude.ai/code і мобільна апка

Хмарна сесія не ставить плагіни ні з user-налаштувань, ні з `.claude/settings.json` репозиторію. Мод підключається через налаштування хмарного оточення:

1. **Setup script**:
   ```bash
   git clone --depth 1 https://github.com/avaver/claude-session-map /root/claude-session-map
   ```
2. **Environment variables**:
   ```
   CLAUDE_CODE_PLUGIN_DIRS=/root/claude-session-map
   ```

Нові сесії в цьому оточенні стартуватимуть із мапою.

## Розробка

```bash
claude plugin validate .
claude plugin test .
```

Код: `hooks/map.ts` містить логіку дерева, `hooks/register.tsx` містить інструмент, панель, рядок у чаті та статус-рядок, а `types/index.d.ts` описує стан мода.
